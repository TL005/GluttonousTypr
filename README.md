# GluttonousTypr
A script that corrects spelling on PC

Installation :
1. Download ALL files
2. Run Command Prompt as admin
3. Type `pip install pynput symspellpy transformers torch pystray pillow pygetwindow pywin32 onnxruntime "optimum[onnxruntime]" peft datasets language-tool-python pyinstaller pytest --extra-index-url https://download.pytorch.org/whl/cpu`
4. Type `winget install Microsoft.OpenJDK.21`
5. Type `python` + FILEPATH
